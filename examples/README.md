# Interface examples

`agent_outputs.json` contains hand-written payloads for contract integration tests. They are not actual model outputs or expected rulings for the case. Never include this file in agent input.

The final-ruling example illustrates an upheld charge with zero refund cents. It does not settle DISP-002: the pickup ambiguity and contradictory event description remain visible in the other examples.

See `docs/PERSON_B_HANDOFF.md` for the working integration example, policy assumptions, and remaining work.
